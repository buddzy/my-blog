이 글은 블로그의 마크다운 파서가 지원하는 문법을 모아 둔 예시입니다. 새 글을 쓸 때 참고하세요.

## 텍스트 강조

**굵게**, *기울임*, ~~취소선~~, 그리고 `인라인 코드`를 쓸 수 있습니다.
줄 끝에 공백 두 칸을 넣으면  
이렇게 줄이 바뀝니다.

## 링크와 이미지

[MDN 웹 문서](https://developer.mozilla.org/ko/)처럼 외부 링크는 새 탭에서 열립니다. [첫 글](post.html?slug=hello-world)처럼 내부 링크도 됩니다.

## 목록

순서 없는 목록:

- 사과
- 바나나
  - 송이 바나나
  - 몽키 바나나
- 체리

순서 있는 목록:

1. 마크다운 파일을 `posts/`에 만든다
2. `posts/posts.json`에 파일 이름을 추가한다
3. 브라우저에서 확인한다

할 일 목록:

- [x] 파서 만들기
- [x] 다크 모드
- [ ] 댓글 기능

## 인용문

> 단순함은 궁극의 정교함이다.
>
> 인용문 안에서도 **강조**를 쓸 수 있습니다.

## 코드 블록

```js
export function greet(name) {
  return `안녕하세요, ${name}님!`;
}
```

HTML은 그대로 실행되지 않고 글자로 보입니다.

```html
<script>alert('실행되지 않아요');</script>
```

## 표

| 문법 | 예시 | 지원 |
| :--- | :--- | :---: |
| 굵게 | `**텍스트**` | ✅ |
| 표 | `\| a \| b \|` | ✅ |
| 각주 | `[^1]` | ❌ |

---

본문에 직접 쓴 <b>HTML 태그</b>도 이스케이프되어 안전하게 표시됩니다.
